# Architecture Decision Records

ADRs document **why** the code looks the way it does. They are required before implementation when a milestone lists them under **ADRs required**.

## Index

| ADR | Title | Status |
|---|---|---|
| [0001](0001-record-architecture-decisions.md) | Matching engine core architecture | Accepted |

## Creating a new ADR

1. Copy [`template.md`](template.md) to `NNNN-short-title.md` (next sequential number)
2. Set status to `proposed`; discuss if needed
3. Set to `accepted` before dependent code merges
4. If superseded, mark old ADR `superseded` and link to the replacement

# Independent validation reports

Executable reviews by an independent spec-author validator (cold clone, offline build, full test suite, gate re-runs). These are **source documents** — not generated by the implementation team.

Reports are immutable once filed. Follow-up reviews get a new versioned file; remediation is tracked in milestone docs, ADR amendments, and [roadmap CHANGELOG](../roadmap/CHANGELOG.md).

## Filing convention

```
docs/validation/
  README.md
  phase-XX/
    YYYY-MM-DD-vN-<short-sha>.md   # validator report (verbatim)
    YYYY-MM-DD-ratification-response.md   # implementer response (optional)
```

When a validator issues a new report, add a row to the index and commit the full text — do not overwrite prior versions.
